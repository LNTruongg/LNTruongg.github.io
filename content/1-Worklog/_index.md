### Introduction

This worklog records my AWS learning journey in the First Cloud Journey program, following a 12-week plan from September 14, 2026, to December 5, 2026.

During the program, I start with basic AWS services such as EC2, S3, and VPC, then move on to databases, serverless, monitoring, and other AWS services. My learning mainly involves reading documentation, following tutorials, and doing some basic hands-on exercises. I also focus on managing AWS resources, choosing free learning activities when possible, and avoiding unnecessary costs.
