### Week 3 Objectives:

- Learn how to manage data access permissions in Amazon S3.
- Learn about S3 Versioning to store and recover file versions.
- Learn about S3 Storage Classes and how to choose the appropriate one.
- Learn how to manage data automatically using S3 Lifecycle.
- Learn how to create a simple static website using Amazon S3.

### Week 3 Achievements:

**Knowledge Gained:**

- Understand how to manage data access permissions in Amazon S3 using Bucket Policy.
- Know that S3 Versioning helps store multiple versions of the same file and supports data recovery.
- Distinguish between several S3 Storage Classes, such as Standard, Standard-IA, and Glacier.
- Understand that S3 Lifecycle helps automatically transition storage classes or delete files over time.
- Know that Amazon S3 can be used to store and serve files for a static website.

**Practice Labs in the Materials:**

- Enable S3 Versioning, upload files, and check file versions.
- Create an S3 Lifecycle Rule to manage file retention periods.
- Upload HTML files to S3 and learn how to configure Static Website Hosting.
- Check and delete unused resources to limit costs.

**Challenges Encountered:**

- Spent quite a lot of time learning about the different S3 Storage Classes because there are many types with different features and costs.
- When practicing S3 Static Website Hosting, the website was initially inaccessible because the bucket access permissions had not been configured correctly.
