Event 2 - AWS Cloud and AI Day Hanoi

Event Introduction

On September 29, 2026, I attended a viewing party in Ho Chi Minh City to follow AWS Cloud and AI Day Hanoi, an event held in Hanoi, Vietnam.

The event focused on cloud computing, artificial intelligence, software development, and modern technology solutions used by businesses.

Through the presentations, I had the opportunity to learn more about cloud architecture, AI Agents, AI-assisted software development, cloud security, and system operations.

Event Information

  • Event Name: AWS Cloud and AI Day Hanoi.
  • Date: September 29, 2026.
  • Main Event Location: Hanoi, Vietnam.
  • My Attendance Location: Ho Chi Minh City, Vietnam.
  • Participation Format: Viewing party, following the event presentations.

Topics Explored

1. Cloud Architecture and System Scalability

One of the topics discussed during the event was how to design systems that can serve large numbers of users while maintaining performance and availability.

The presentations introduced several challenges in distributed systems, especially when the amount of data and the number of requests increase.

I also learned about Amazon Dynamo, a key-value storage system designed to support scalability and availability in distributed environments.

This session helped me understand that cloud application development involves more than implementing features. Developers must also consider scalability, reliability, and operational efficiency.

2. AI Agents and Modern AI Applications

Another topic I found interesting was the development of AI Agents and AI-native applications.

The presentations explored how AI Agents can support workflow automation, task processing, and improved productivity in organizations.

However, deploying AI in real-world environments also presents several challenges:

  • Controlling the quality of AI-generated outputs.
  • Ensuring that AI systems operate within their intended scope.
  • Reviewing and validating AI-generated results.
  • Maintaining human oversight for important tasks.

From this session, I realized that building an AI application involves more than connecting to a language model. A reliable system also requires a well-designed workflow, testing, and appropriate management mechanisms.

3. AI-Assisted Software Development

The event also introduced new approaches to software development, particularly the use of AI Coding Assistants and AI Agents to support developers.

AI tools can assist programmers in understanding source code, suggesting solutions, and handling certain development tasks.

However, AI-assisted development still needs to be combined with essential software engineering practices, including:

  • Requirements analysis.
  • System architecture design.
  • Functional testing.
  • Security assessment.
  • Monitoring and continuous improvement.

This session helped me recognize that AI tools can improve development productivity, but programming knowledge and problem-solving skills remain essential.

4. Cloud Security and System Operations

Security is an important consideration when developing and deploying cloud applications.

The presentations covered topics such as vulnerability detection, automated security testing, and approaches to maintaining secure system operations.

I learned that security should not be considered only after an application has been completed. Instead, it should be integrated throughout the development lifecycle.

In addition, system monitoring plays an important role in identifying issues and supporting incident response.

5. AWS Solutions and AI Adoption in Enterprises

Another topic discussed during the event was how businesses can combine AWS services with artificial intelligence to develop technology solutions.

The presentations highlighted the role of cloud platforms in providing infrastructure, supporting data processing, deploying AI applications, and monitoring system operations.

Through this topic, I gained a broader understanding of how Cloud and AI technologies can work together to address practical business challenges.

Key Takeaways

After following the presentations, I summarized several important lessons:

  • Gained a better understanding of scalability and availability in cloud systems.
  • Learned more about distributed systems and the challenges of supporting large numbers of users.
  • Explored the development of AI Agents and AI-native applications.
  • Recognized the role of AI in supporting software development and workflow automation.
  • Understood that AI-generated results still require evaluation and validation.
  • Learned more about cloud security, monitoring, and system operations.
  • Gained insights into how AWS can support businesses in developing and deploying AI solutions.

Connection to My Personal Project

I am currently developing a restaurant recommendation and itinerary planning application for Ho Chi Minh City.

Based on the topics presented at the event, I identified several concepts that may be useful for my project.

First, developing a recommendation system requires attention to data quality and the ability to process user requests effectively. As the number of restaurants and users increases, system scalability may also become an important consideration.

In addition, the AI-related topics helped me recognize the importance of evaluating recommendation results rather than relying entirely on system-generated outputs.

The discussions about cloud security and operations also provided a foundation for exploring AWS deployment options in the future.

These are potential areas for future development. They do not mean that all the technologies discussed at the event have already been implemented in my project.

Personal Experience

Attending the viewing party gave me an opportunity to explore Cloud Computing and AI through presentations about real-world applications.

Among the topics discussed, I was particularly interested in AI Agents and how AI can support the software development process.

Some concepts related to distributed systems and cloud architecture were still relatively new to me, so I plan to continue learning through documentation and practical exercises.

Overall, the event broadened my perspective on AI and Cloud technologies and helped me recognize the importance of combining programming, system design, and application operations.
